# Taste

Use this as the single executable router for Taste work.

## Routing

- Route by desired visual mode: brand kit, minimalist, brutalist, soft, GPT, Stitch, redesign, image-to-code, or output polish.
- Keep product/UI rules active; load only the visual-mode reference the task calls for.
- Treat package, font, and icon mandates inside a folded upstream reference as
  mode-local suggestions. They cannot override the incumbent project's design
  system, exact licensing, or Kevin's current admission contracts. In
  particular, do not globally ban or replace an icon family: run the coverage,
  one-family/style, wrapper, accessibility, and bundle gate in
  `wiki/design/ui-design-defaults.md`.

## Reference Loading

Load one folded reference at a time. Prefer the most specific reference that matches the user's named service, framework, command, or error. If no folded reference matches, use the router guidance here and verify with primary docs or local project state.
