# Sentry

Use this as the single executable router for Sentry work.

## Routing

- SDK setup routes by platform or framework to the matching folded reference.
- Issue work routes to workflow, fix-issues, create-alert, code-review, or PR review references.
- Observability work routes to OpenTelemetry exporter setup and AI monitoring references.

## Reference Loading

Load one folded reference at a time. Prefer the most specific reference that matches the user's named service, framework, command, or error. If no folded reference matches, use the router guidance here and verify with primary docs or local project state.
