# PostHog

Use this as the single executable router for PostHog work.

## Routing

- Instrumentation routes to product analytics, feature flags, error tracking, logs, LLM analytics, and integration references.
- Analysis routes to experiments, replays, heatmaps, metrics, autocapture, live traffic, traces, costs, and evaluations.
- Operations routes to stale flags, warehouse syncs, endpoints, subscriptions, alerts, signals, and triage references.
