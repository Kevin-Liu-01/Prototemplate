# Azure

Use this as the single executable router for Azure work.

## Routing

- Deployment starts with planning; preserve the Azure plan-first workflow from the folded azure-prepare reference.
- Resource operations use read-first lookup before mutation, then deployment/validation references as needed.
- Security and governance prompts route to RBAC, compliance, quotas, cost, and reliability references.
- Specialized products route to Kusto, Messaging, Kubernetes, Storage, AI Gateway, Foundry, App Insights, Entra, or hosted Copilot references.

## Reference Loading

Load one folded reference at a time. Prefer the most specific reference that matches the user's named service, framework, command, or error. If no folded reference matches, use the router guidance here and verify with primary docs or local project state.
