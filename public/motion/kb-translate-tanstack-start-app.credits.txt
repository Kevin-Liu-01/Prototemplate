kb-translate-tanstack-start-app: credits and sources
How do I translate a TanStack Start app? One of General Translation's product films, for its
TanStack Start library page. The end card points to the docs page,
generaltranslation.com/docs/react/tanstack-start-quickstart.
Film: the story cut, 48.90 s, 1920 x 1080, 60 fps, built 2026-10-14 in the story format, with
the key words of each heading and of the answer in the blue accent.

SCRIPT
- From General Translation's docs page "TanStack Start Quickstart" (generaltranslation/content
  docs/en-US/react/tanstack-start-quickstart.mdx, main 361ec4a), with the TanStack Start setup
  page beside it (docs/en-US/react/(frameworks)/tanstack-start/setup.mdx). The film tells it as a
  story: someone in Kyoto whose browser asks for Japanese gets a TanStack Start page in English,
  because the server renders the same English JSX for every request and nothing reads the
  request's language. The answer on the answer card names General Translation as its subject:
  "General Translation lets you translate a TanStack Start app with gt-tanstack-start." The steps
  are the quickstart's: the experimental gt-tanstack-start package and initializeGT with the
  languages and a loader, gtMiddleware and the root route's loader for GTProvider, <T> round the
  page, and npx gt translate. Kyoto is a sample place; the film says nothing about anyone there.
  The code, commands and file names are checked against the docs and the open-source code
  (generaltranslation/gt at 1048f50: gt-tanstack-start 11.4.12, gt-react 11.4.12, gt 2.26.5).
  BRIEF.md cites each one.

CODE ON SCREEN
- src/routes/index.tsx before and after <T>, the two install commands, src/router.tsx with
  gt.config.json, src/start.ts, the root route's options in src/routes/__root.tsx, and the
  sign-in and translate commands: the quickstart's code, reflowed where a row would not fit the
  panel, as BRIEF.md section 4 says. The app is the TanStack CLI's blank template
  (@tanstack/cli 0.71.1) with the quickstart's page text.

THE APP PAGE
- The page's English strings are the quickstart's: Welcome to my app, This content is translated
  automatically. The Spanish and Japanese strings are drafts written for this film; they are not
  output of General Translation's API, and they wait for a native speaker's review. kb.json
  (scene.screen.blocks) holds every one of them.
- The language code over the page's corner (ja, es) is the language the visitor's browser asks
  for.

MARKS
- The doubled-line GT mark (kit/brand/gt-mark.svg), small in the lower left corner of the answer
  card, and the General Translation lockup, the bar monogram over the name
  (kit/marks/bar-monogram-lockup.svg), on the end card.

TYPE
- Inter (rsms/inter, SIL Open Font License 1.1), kit/fonts/InterVariable.woff2, through var(--font).
- Geist Mono 1.701 (vercel/geist-font, SIL Open Font License 1.1, kit/kb/fonts/OFL.txt) for code.
- Japanese is set in the machine's Hiragino Sans, which kit/kb/kb-story.js names by the text's
  language; no face is fetched.

VOICE
- Narrator: Frederick Surrey, an ElevenLabs library voice (eleven_multilingual_v2, stability 0.55,
  style 0.2, speed 1.0; kit/audio/voice.json). Seven takes, one per line, through kit/kb/take.mjs
  and kit/audio/el.mjs, recorded 2026-10-14: three lines recorded more than once (the first line
  five times, the answer four times and the middleware line twice), one take of each used. The
  answer was sent with the question before it so it reads as a reply. None is slowed, sped or
  stretched.

MUSIC
- The product films' series bed: composed for the series by the ElevenLabs Music API (music_v1,
  instrumental, 60 s, 2026-10-09; kit/kb/audio/series-bed.prompt.txt), cut to this film on its own
  bar lines by kit/kb/mix.py so its held chord falls on the end card.

DRAWING
- The drawing grammar of films/gif-how-gt-works (vector interface panels, doubled-line connectors,
  black and white with one blue accent), through motion/kit/kb, its story stage
  (kit/kb/kb-story.js) and its screen module (kit/kb/kb-screen.js) for the app page.
