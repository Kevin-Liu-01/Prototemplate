# FV layout idea bank — Kenshi Tsukamoto (@dezainaz_ceo), v1

Source: https://x.com/dezainaz_ceo/status/2084546010953703895 (Aug 4 2026,
"困った時に使える WebサイトのFVレイアウトアイデア16選" — 16 first-view layouts,
all monochrome Japanese editorial). Images: fv-1..4.jpg, four concepts each.
Kevin: "these are fantastic concepts we can use for display and so on."

The whole set is ink/paper, ruled hairlines, mono numerals — native to our
system. The concepts most worth stealing, mapped to GT surfaces:

- **Type-specimen hero** (fv-1: 永/あ with weight/width/contrast slider
  rows) → a locale/type playground; the slider triple is a house-grade
  control grammar for any parameterized demo (exposure, speed, locale count).
- **Temperature rail** (fv-4: bath lab, 44°C→32°C stops with the active stop
  boxed) → stepped selector rail; would suit locale-count or latency scales.
- **Ticket CTA** (fv-4: night train, perforated ticket "乗車する →" beside a
  station/time ledger) → Deploy-band CTA as a boarding pass; the station
  ledger doubles as an edge-region latency table.
- **Exploded diagram + receipt** (fv-2: PENTAX A7319 parts grid + repair
  ledger) → cousin of our stack iso; the intake-receipt ledger is an audit
  -log display grammar.
- **Waveform spine** (fv-2: soundscape hotel — vertical waveform axis with
  named rooms hanging off it) → Signal home's motif, literally.
- **Constellation timeline** (fv-3: dark museum, artifacts as nodes labeled
  1603→2071 + collection count 1,286) → enterprise heritage/trust wall.
- **Leader-line swatch plates** (fv-4: tilted material plates with 紙/金属/
  繊維/ガラス labels on hairline leaders) → integrations/frameworks display.
- **Radial process dial** (fv-3: food co-op ingredient clock, numbered steps
  01–04 on the rim) → onboarding/pipeline loop.
- **Observation log** (fv-2: fermentation — circular micro photos + specimen
  stats rail 温度/比重/pH/経過日数) → live metrics band grammar.
- **Blueprint-over-photo** (fv-3: reclaimed architecture, wireframe section
  dissolving into the photographed cliff + elevation ticks) → "rendered app
  over payload" reveal, at hero scale.
- **Vertical-type + archive ledger** (fv-1: dance archive) and **scent haiku
  columns** (fv-3: perfume) → vertical text columns are viable for CJK locale
  storytelling moments.
