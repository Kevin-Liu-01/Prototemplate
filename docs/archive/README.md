# Archive

Finished round specs, kept as design history. Nothing here is maintained or served on the site, and the current rules are in the canon (`BRAND.md`, `DESIGN.md`), the handbook and the skills. A rule in one of these files that the canon does not repeat is no longer a rule.

| File | What it was | Moved from |
| --- | --- | --- |
| `DESIGN_STANDARD.md` | The diagram standard of 2026-07-29: values measured from generaltranslation.com, resend.com, viteplus.dev and oxc.rs, and the bar each cell was judged against | `docs/research/` |
| `ITERATION_SPEC.md` | The founder review round of July: each switcher position mapped to its slug, and the global bans | `docs/research/` |
| `MODULES_PLAN.md` | The build contract for five minimalist directions, organized by module so five builders could work in parallel | `docs/research/` |
| `PORT_SPEC.md` | The brief for porting one HTML exploration into the July explorations app | `docs/research/` |
| `feature-inventory.md` | GT's capabilities, each with the real artifact a page can show for it | `docs/research/` |
| `landing-content.md` | The copy, customers, section order and code panels of the landing page in July | `docs/research/` |
| `deck-round-5.md` | The brief for round five of the brand deck (2026-09-09); its paths are relative to `deck/` | `deck/ROUND-5.md` |

The files moved on 2026-10-10. Where one names a sibling file without a folder, the sibling is in `docs/research/` or here. In the paths they cite, `$GT` is a checkout of `generaltranslation/gt`, `$GT_CLOUD` a checkout of gt-cloud, and `<scratchpad>` the scratch folder of the session that wrote the file, which no longer exists. The two screenshot probes those sessions ran (`shoot-route.mjs` and `rhythm-probe.mjs`, formerly `docs/harness/`) are in git history; `pnpm capture:pages --direction <slug>` replaces the first.
