The docs

The docs have 393 pages in eight sections and are served in eight locales from one English source. The palette is neutral gray with hairlines instead of shadows and one accent color for the active sidebar row and the table-of-contents indicator. Sidebar indentation is drawn as vertical rails, and the controls sit in one floating toolbar.

The palette follows Vercel's Geist grays. The sidebar rails use Fumadocs' own table-of-contents indicator technique, related pages follow the Next.js docs convention, and the markdown versions follow llmstxt.org.
