Type scale

Each page uses one type scale. Headings use weight 500 with negative letter-spacing. On desktop the hero headline scales with the viewport up to 3.7rem. The accent color is never applied to a heading; emphasis is a doubled underline in the text color. Below 720px the hero is fixed at 2.5rem and every other size comes from the token ladder shown here.
