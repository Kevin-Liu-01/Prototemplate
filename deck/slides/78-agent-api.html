The agent API

The studio and the agent interface use the same identities, catalog and generation language. Agents discover the site through llms.txt, a versioned manifest and an OpenAPI 3.1 document, generate deterministic SVG over HTTP, and drive the live studio through a browser API that reads and applies the same source the inspectors edit.

/llms.txtThe operating guide in 194 lines; /llms-full.txt carries the complete documentation corpus.
/api/agentThe manifest, version 0.2.0: interfaces, policies, execution rules and the generation schema.
/openapi.jsonThe OpenAPI 3.1 document, eleven paths, and the catalogs: labs, materials, identities, elements.
/api/elements89 brand elements in seven categories, from digital to physical.
/api/generatePOST a kind: background, template, element-brief or design-sequence, as JSON or raw SVG.
window.glyphfield.studiodescribe, controls, activate, set, readSource, applySource, invoke and download.
SkillsFour repository skills, one per task: create, api, studio and export.
