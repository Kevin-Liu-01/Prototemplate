Thirty visuals for the six places that ask for one

Each place in the draft that asks for a picture has five structurally different versions: a literal overlay, an abstraction, a comparison, a diagram, and a specimen or list. Every screenshot is a real crop of the live docs captured at 3x to 5x. The visuals carry labels only, set in Inter and Geist Mono in one blue; deletions and anti-patterns use one muted red. Every background is a different frame from the pool.

Rendered at 7680 wide and downsampled 2x to 3840 by 2160. The table of contents visual also ships as a recording of the active marker sliding down the rail. Every visual is an HTML file, and one generator rebuilds all thirty-two from a manifest.
