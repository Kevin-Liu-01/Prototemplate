Typography

Inter is the one typeface for display, interface and text, loaded as one variable file with an optical size axis. Headings use weight 500 at most. Long-form text and documentation are set at weight 400. Monospace is used only for code, tokens, and technical labels.

This is the working typeface going into the identity project. It is not a final decision. Alternatives remain open if they cover the required scripts.
