Markdown twins

Developers and coding agents read the same docs. Every page is also published as markdown, and the Copy page menu can open it in Claude or ChatGPT.

Currently only the English versions are prebuilt. The seven translated locales are covered by a fix now in review.

MarkdownData-driven components, such as the supported-locales table, are expanded into plain markdown.
PreferenceFramework preference is stored in a cookie and the URL, so each variant is a separately cached page.
SearchPagefind indexes the built HTML after every deploy, with one index partition per locale.
LocalesThe English tree defines structure and locale trees supply labels, so every sidebar lists every page.
