The doubled line

The standard connector in diagrams is one SVG path stroked twice: a wider stroke in the text color, then a narrower stroke in the background color on top. The result is two parallel 1.5px lines with a 3px gap that follow any curve. An animated pulse is a third copy of the same path in the accent color. Where paths join, the second stroke merges the junction into one clean pair.

The gauge is 1.5px, the gap is 3px, and the strokes do not scale with the drawing. Draw order is all outer strokes, then pulses, then all inner strokes.
