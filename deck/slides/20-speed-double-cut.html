Double cut

The name is set as one line in Anybody at width 150, black and upright. Two cuts run through the line at 40 and 60 percent of the cap height, each 7 percent of the cap thick. The pair of cuts reads as speed without a slant, so this is the calmest direction in the set, and it sits well next to Inter body copy.

Shown at the full width of the sheet, 1326 px. The cuts are two rectangles in a mask over one path, so the file stays one color.
