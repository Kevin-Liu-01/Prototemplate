A Next.js 16 site with fumadocs docs and live canvas fields fails in ways the browser rarely reports: a field draws black, a click paints an empty layout, two builds of one page differ. This site and generaltranslation.com, General Translation's site, met each of these traps between July and October 2026, and every fix comes with its numbers and the file, lint or skill that keeps it from coming back.

## Ten traps

| Symptom | Cause | Fix |
| --- | --- | --- |
| [A WebGL field draws black after a dozen client-side navigations, with no error](/docs/engineering/engines#the-context-budget) | Chrome keeps about 16 live WebGL contexts, and each mount made one | One engine and one context per engine module for the session |
| [Every route of the dev server answers 500 with "Unexpected non-whitespace character after JSON"](/docs/engineering/dev-servers#failure-modes-of-next-dev) | `next dev` under load left its prerender manifest half written | Stop the server by PID, delete `.next/dev`, start it again |
| [A click on a docs folder paints the layout with no article for about 280 ms](/docs/engineering/docs-traps#links-that-point-at-leaf-pages) | The page threw `redirect()` during render | Link to the leaf page; redirect in `next.config.ts` |
| [Two builds of one page ship different code colours](/docs/engineering/docs-traps#code-highlighting-across-builds) | Shiki stops tokenizing a line after 500 ms on a loaded machine | `tokenizeTimeLimit: 0` |
| [A Markdown twin answers 200 locally and 500 in production](/docs/engineering/docs-traps#markdown-twins-in-production) | The route read MDX from disk, which the deployed function does not have | Prerender every twin with `dynamicParams = false` |
| [Utilities such as `font-semibold` and `mt-6` do nothing on headings](/docs/engineering/docs-traps#unlayered-rules-and-layered-utilities) | An unlayered reset outranks Tailwind 4's layered utilities | Metrics in the section's stylesheet, gaps on the parent |
| [A canvas goes soft after browser zoom](/docs/engineering/engines#browser-zoom) | Zoom changes `devicePixelRatio` without resizing the box | Watch the resolution media query and re-arm it on every change |
| [Shader and dither canvases come back blank in an embedded browser pane](/docs/engineering/verification#the-in-app-browser-pane) | The pane reports the page hidden and pauses `requestAnimationFrame` | Take pixels with Playwright in Chrome for Testing |
| [A translated Lottie animation draws nothing after one text layer](/docs/engineering/lottie#a-missing-glyph-stops-the-frame) | A character missing from the glyph list throws inside lottie-web's canvas text | An empty glyph entry for every drawable character |
| [Strings render in English in every locale](/docs/engineering/i18n-routing#links-routers-and-strings-in-gt-next) | The `gt generate` command does not follow a `gt` destructured out of `Promise.all` | `const gt = await getGT();` on its own line |
