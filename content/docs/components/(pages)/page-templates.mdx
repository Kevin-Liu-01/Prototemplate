The hub builds its pages from four types. A book page is a hub route inside the viewer shell, a docs page is the layout you are reading, an article is a post on the production mirror's blog, and the error page is the mirror's 404 page. Each plate frames a live page of one type. Anatomy outlines every part, draws its spacing as a hatched band, and labels the part with its spacing token and the value the page computes at the frame's width.

## Book page

Every hub page with a book head has one structure, set by DESIGN.md section 4 and held by `pnpm lint:heads`. Page picks a route built on it, and the labels change with Width because the tokens step down under 900 pixels.

## Error page

An address the production mirror does not hold renders the shipped 404 page and answers with HTTP status 404: the nav, one band with the horizon, the apology inside its hole, the two exits, the code in the corner, and the site footer.

<PageTemplateDemo template='error' />

| Part | Component | File | Spacing token |
| --- | --- | --- | --- |
| Nav | `ProdNav` | `src/app/d/production/sections/ProdNav.tsx` | `height: 56px` and a 1px rule |
| Band | `NotFound` | `src/app/d/production/sections/not-found.css` | `min-height: clamp(560px, calc(100svh - 58px), 920px)` |
| Horizon | `NotFoundHorizon` | `src/app/d/production/sections/NotFoundHorizon.tsx` | `--pnf-hole-radius`, placed at `--pnf-hole-x` and `--pnf-hole-y` |
| Copy | `NotFound` | `src/app/d/production/sections/NotFound.tsx` | `width: min(calc(var(--pnf-hole-radius) * 1.55), calc(100% - 40px))` |
| Exits | `NotFound` | `src/app/d/production/sections/NotFound.tsx` | `margin-top: 28px` |
| Code | `NotFound` | `src/app/d/production/sections/not-found.css` | `right: 24px` and `bottom: 18px` |
| Footer | `ProdFooter` | `src/app/d/production/sections/ProdFooter.tsx` | `--tc-rail`, 1104px |

The horizon computes the hole's center and radius from the band's width and height in `NotFoundHorizon.tsx` and sets them as `--pnf-hole-x`, `--pnf-hole-y` and `--pnf-hole-radius`, and the copy is placed on that center. The overlay reads the same three properties and draws the hole as a circle. The footer fills the width at 390 pixels, so the plate labels it at 1440 only.

## Frames

Each plate keeps one live page, created when the plate comes within 180 pixels of the viewport and removed when it leaves, as the [page gallery](/docs/components/page-gallery) does. The overlay reads the framed document directly, because the frame is same-origin. It measures the parts on load, on every scroll inside the page and on every resize, and it never takes a pointer, so the page under it stays live.
