Every mark in Prototemplate is one color in `currentColor`, so the same file draws positive on paper and reversed on ink with no redraw. Every mark is an SVG file under `public/marks`, listed with its notes in the catalog of `src/lib/marks.ts` and shown in full at [/marks](/marks). The chosen logo, Axis and meridian behind, leads the shortlist, with its state on hover, on sign-in and while loading, Oval globe, axis behind, after it, and [/marks/graticule](/marks/graticule#progression) shows the marks that led to both. The mark in production on generaltranslation.com, the doubled-line monogram, is a path that `GtMark` draws inline.

## The marks

The plate draws any mark at the heights `/marks` shows it: a monogram from the 16 pixel favicon to the 128 pixel app icon, a wordmark at 48, 96 and 144. It opens on the shortlist, led by the logo, each mark cut to its drawn box, and Family switches to the seven speed marks, the two picture marks of the earlier round and the five globe concepts. Ground switches paper and ink, and Construction shows the build overlay of a picture mark.

<MarksDemo />

Under a monogram the plate repeats it at 16, 24 and 32 pixels at their true size, where a mark either holds up as a favicon or does not. The server half of the demo reads the files at build time and passes them to the client inline, so the page fetches no mark files. The hemispheres stay on `/marks`, which draws every mark as a mask of its file.

### Import and data

```ts
import { boxMask, CATALOG, catalogMark, shortlist, SHORTLIST } from '@/lib/marks';

const best = shortlist(); // the shortlist's rows in page order
const stencil = catalogMark('stencil-gt'); // { id, name, family, file, box, pick }
const crop = stencil?.box ? boxMask(stencil.box) : undefined; // CSS mask size and position for the drawn box
```

| Export | What it holds |
| --- | --- |
| `CATALOG` | Every mark as one row: `id`, `name`, `family`, the public `file`, `file16` and `constructionFile` where drawn, `box` (the drawn box in the 256 unit square, for the marks from 2026-10-28 on), `pick`, `use` (`logo` or `state`, on the two marks Kevin chose for a job) and `note` |
| `SHORTLIST`, `shortlist()` | The ids of the chosen marks in page order, at most 16, and their rows: the logo first, then its state |
| `FAMILIES`, `pageFamilies()`, `dynamicFamily(id)`, `familyLead(id)` | Each family's name, one sentence and anchor on `/marks`; the families in page order; a family's marks in order; the mark a family leads with |
| `DYNAMIC_MARKS` | The marks from 2026-10-28 on, each a file under `/marks/dynamic/`, except the logo and its state, whose files are their drawings under `/marks/graticule/variations/` |
| `boxMask(box)` | The mask size, position and aspect that show only a mark's drawn box of its square file |
| `MARKS`, `GLOBE_CONCEPTS` | The nine speed and picture marks with their notes, and the five globe concepts under `/marks/globe/` |
| `MARK_SIZES`, `WORDMARK_SIZES` | The heights in CSS pixels: 16, 24, 32, 64 and 128, then 48, 96 and 144 |
| `LOGO` (in `src/lib/logo.ts`) | The logo as one path with its fill rule, its 256 unit square and its drawn box, the drawing the chrome, the deck and the masters read |

`pnpm import:marks` copies finished marks into `public/marks/dynamic` from a manifest kept outside the repository, checks each with the mark checker and prints its drawn box for its row; `pnpm test:marks` holds every row to its file. `pnpm build:marks` generates the seven speed files from `scripts/build/speed-marks.mjs` with tight view boxes, so a viewer sizes each mark by height and its own aspect.

### When to use it

Draw a mark inline, or as an alpha mask in `currentColor`, so it takes the ink of its ground. Beside the stacked name, "General" over "Translation", the globe is 1.1 times the span from the first line's cap top to the second line's baseline, which is 2.4627 cap heights, and is centred on that span, so it overshoots the cap top and the baseline by 0.1231 cap height each, as a round letter such as O overshoots flat ones. The gap from the globe's ink to the G is 0.5637 cap height. The name in the lockup is Katagami Text at weight 500, letter-spacing 0, with the font's kerning, drawn as outlines, the two lines flush left by ink with 0.4627 cap height of white between the first baseline and the second cap line. `pnpm build:lockup` draws `public/brand/gt-globe-lockup.svg` and its light and dark files, the deck's `#gt-lockup` and the globe rows' name from the font and `LOGO`. Running text writes the name out as General Translation in Inter and never sets the logo inside a sentence. The register's one-color rule holds for every use: no second tone, no gradient, no stroke and no shadow. The plate mark is the one mark that brings its own ground: its letters and stripes are holes, so it is an ink plate on paper and a paper plate on ink.

### Reduced motion and themes

The marks do not move. On the ink ground the same file draws in paper ink.

## The chrome mark

`GtMark` draws the logo alone as a block SVG in `currentColor`, at the sizes the chrome uses: 25 by 16 in the sidebar and the toolbar, 28 by 18 in the sheet frame, and 50 by 32.

### Import and props

```tsx
import { GtMark } from '@/components/viewer/GtMark';

<GtMark width={28} height={18} />;
```

| Export | Props | What it does |
| --- | --- | --- |
| `GtMark` | `width` (25), `height` (16) | The mark alone as a block SVG in `currentColor` |

### When to use it

Use `GtMark` where the mark stands alone: the sidebar, the toolbar and the sheet frame. In running text the name is written out as General Translation, and no mark sits inside a sentence.

### Reduced motion and themes

`GtMark` does not move. It fills `currentColor`, so it takes the ink of its ground in both themes.

## The dithered shine

The plate seats the logo as an alpha mask and sweeps a specular band through it, quantized by the 4 by 4 screen into five nested coverage tiers. The cells never move; two clip windows carry the light across them, and the counter-sheen runs half a lap behind. Seat lays the mark flat or on the isometric top plane, Glint picks the light's ink, and the speed is in drawing units a second.

<DitheredMarkDemo />

The mask holds the mark's seat transform inside it, so the masked rectangles stay in screen space and every cell stays a square screen pixel, even on the isometric plane. The tiers nest, so the band reads as one falloff from a solid core to a sparse fringe.

### Import and props

```tsx
import DitheredMark, { shineTravel } from '@/app/d/toolchain/diagrams/DitheredMark';
import { plane } from '@/app/d/toolchain/diagrams/iso';

const cover = { x: -48, y: -37, w: 58, h: 37 };
const { from, to } = shineTravel(cover); // the sweep's endpoints

<DitheredMark
  id='ldx'
  href='/brand/locadex-mark.svg'
  plane={plane(14)}
  markHalf={35}
  cover={cover}
  inkClassName='mark-ink'
  glintClassName='mark-glint'
  shineClassName='mark-shine'
/>;
```

| Prop | Type | Default | What it does |
| --- | --- | --- | --- |
| `id` | string | required | A prefix for the mask, pattern and clip ids, which are global in the document. |
| `href` or `maskContent` | string or SVG | one required | The mark as an image file, or any SVG content filled white. |
| `plane` | string | required | The seat transform, applied inside the mask. `plane(z)` from `iso.ts` seats it on an isometric face. |
| `markHalf` | number | required | Half the image box, for an `href` mark. |
| `cover` | `{ x, y, w, h }` | required | The screen rectangle the ink and the shine span. The sweep derives from it. |
| `maskBox` | `{ x, y, w, h }` | `-120, -80, 240, 160` | The mask's bounds in user space. |
| `cell` | number | `1.05` | The dither cell's edge in drawing units. |
| `tiers` | `ShineTier[]` | `SHINE_TIERS` | The band's coverage tiers, center out: 16, 10, 6, 3 and 1 of 16. |
| `inkClassName`, `glintClassName`, `shineClassName` | string | required | The resting ink, the glint cells and the shine group. |
| `stripeData` | two attribute names | `data-ldx-stripe`, `data-ldx-stripe2` | The attributes on the two bands that the host's tween targets. |

The component draws and the host animates. The host tweens the elements carrying each stripe attribute along x from `from` to `to` with no easing on repeat, and starts the counter-sheen's tween half a lap in, as the stack tower does at 56 units a second.

### When to use it

Use the shine on one mark that is the drawing's subject, such as the Locadex mark on the capstone of the stack tower.

### Reduced motion and themes

Under reduced motion the host never starts the tweens, and the markup's own pose stays: the primary band mid-glyph and the counter-sheen parked clear. The resting ink and the glint read this page's ink, so the mark follows the docs theme.

## Traps

[SVG lines in motion](/docs/craft/svg-motion) explains each of these with its fix.

- The brand deck's `#gt-mark` symbol (`deck/parts/head.html`) is the logo and carries its own viewBox, its drawn box `24.3 24.3 207.4 207.4`. Copied onto the outer svg, a symbol's viewBox shifts the mark and cuts it off. Reference the symbol from an svg with an equal width and height (88 by 88, for example) and no viewBox ([symbols and masks](/docs/craft/svg-motion#symbols-and-masks)).
- A mask with `maskUnits="userSpaceOnUse"` resolves in the user space of the element that uses it, so the mask's coordinates are written in the same plan coordinates as the masked rectangle ([symbols and masks](/docs/craft/svg-motion#symbols-and-masks)).
- SVG ids are global to the document. Two marks on one page with the same `id` share one mask, so each `DitheredMark` gets its own prefix ([symbols and masks](/docs/craft/svg-motion#symbols-and-masks)).
- A `rotate()` clip window moves with GSAP's SVG transform origin, and it shifted the shine's sweep about 180 units off the mark. `DitheredMark` sweeps windows drawn pre-rotated at 60 degrees by a pure horizontal translate for that reason ([GSAP from outside the page](/docs/craft/svg-motion#gsap-from-outside-the-page)).
